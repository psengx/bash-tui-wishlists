# Wishlist Manager — менеджер вишлистов в Bash

## Тема проекта

Терминальная программа для создания и ведения вишлистов — списков желаемых подарков.

## Что умеет программа

1. Создавать новый вишлист.
2. Показывать все созданные вишлисты и количество подарков в каждом.
3. Открывать отдельный вишлист и просматривать его содержимое.
4. Редактировать вишлист: менять название, добавлять и удалять подарки.
5. Удалять вишлист целиком (с подтверждением).
6. Искать подарок по тексту во всех сохранённых списках.

Программа работает в интерактивном режиме: после выполнения действия возвращает пользователя в главное меню.

## Структура проекта

```text
bash-tui-wishlists/
├── app.sh
├── README.md
├── data/
│   └── wishlists/
└── reports/
```

- `app.sh` — основной Bash-скрипт.
- `data/wishlists/` — постоянное хранилище. Каждый вишлист находится в отдельном `.txt`-файле: первая строка содержит название, последующие — подарки.
- `reports/` — папка для материалов демонстрации проекта.

## Требования

- Ubuntu или другой Linux с Bash.
- Стандартные утилиты: `find`, `sort`, `head`, `tail`, `grep`, `wc`, `nl`, `awk`, `mktemp`, `date`, `mkdir`, `rm`, `mv`.

Внешние библиотеки и установка дополнительных пакетов не требуются.

## Запуск

Перейдите в каталог проекта:

```bash
cd bash-tui-wishlists
```

Выдайте скрипту право на выполнение (достаточно сделать один раз):

```bash
chmod +x app.sh
```

Запустите программу:

```bash
./app.sh
```

Также можно запустить командой `bash app.sh`.

## Пункты главного меню

| Пункт | Действие |
|---|---|
| 1 | Создать вишлист |
| 2 | Посмотреть все вишлисты |
| 3 | Открыть вишлист |
| 4 | Редактировать вишлист |
| 5 | Удалить вишлист |
| 6 | Найти подарок |
| 0 | Выход |

В меню редактирования доступны изменение названия, добавление подарка и удаление подарка по номеру.

## Какие темы курса использованы

- **Bash и shebang:** `#!/usr/bin/env bash`.
- **Переменные:** пути к каталогам, пользовательский ввод, выбранный файл.
- **Функции:** отдельные функции для создания, просмотра, редактирования, удаления и поиска.
- **Условия:** `if`, проверки пустого ввода, проверка номера и `case`.
- **Циклы:** главный `while`-цикл и обход списка файлов через `while read`.
- **Файлы и каталоги:** `mkdir`, `touch`-подобная запись через перенаправление, `cat`-совместимые текстовые операции, `mv`, `rm`.
- **Права доступа:** `chmod +x app.sh`.
- **Текстовые утилиты:** `grep`, `wc`, `sort`, `head`, `tail`, `nl`, `awk`.
- **TUI:** меню, ввод пользователя, обработка выбора, пауза и возврат в меню.

## Пример проверки

1. Запустить `./app.sh`.
2. Выбрать `1` и создать вишлист `День рождения`.
3. Выбрать `4` → нужный вишлист → `2` и добавить `Наушники`.
4. Повторить добавление для `Книга по Linux`.
5. Выбрать `2` и убедиться, что список появился.
6. Выбрать `3`, открыть вишлист и проверить его содержимое.
7. Выбрать `6`, ввести `наушники` и проверить поиск без учёта регистра.
8. Выбрать `4` → `3`, удалить один подарок по номеру.
9. Выбрать `5` и удалить тестовый вишлист, подтвердив действие.

Дополнительные команды для демонстрации структуры и прав:

```bash
find . -maxdepth 3 -type f -print
ls -l app.sh
./app.sh
```

Проверить сохранённые данные можно отдельно:

```bash
ls -l data/wishlists/
cat data/wishlists/*.txt
```

Данные не теряются после завершения программы: они остаются в текстовых файлах внутри `data/wishlists/`.
